**1. Steps to create branches in Git repository and merge the files of branches into Main branch**

**Step 1:** Initialize Git repository.

```bash
git init
```

**Step 2:** Create a new branch.

```bash
git branch branch1
```

**Step 3:** Switch to the new branch.

```bash
git checkout branch1
```

**Step 4:** Add and commit the files.

```bash
git add .
git commit -m "Added files"
```

**Step 5:** Switch to the Main branch.

```bash
git checkout main
```

**Step 6:** Merge the branch into Main.

```bash
git merge branch1
```

**Step 7:** Push the changes to GitHub.

```bash
git push origin main
```

---

**2. Difference between PUSH and PULL commands in Git**

**PUSH:** The `git push` command is used to upload local commits and changes to the remote repository such as GitHub.

Example:

```bash
git push origin main
```

**PULL:** The `git pull` command is used to download the latest changes from the remote repository and update the local repository.

Example:

```bash
git pull origin main
```

**Difference:**

* PUSH: Local repository → Remote repository
* PULL: Remote repository → Local repository

---

**3. Use of CHECKOUT and COMMIT commands in Git**

**CHECKOUT:** The `git checkout` command is used to switch from one branch to another.

Example:

```bash
git checkout branch1
```

**COMMIT:** The `git commit` command is used to save the staged changes in the local Git repository.

Example:

```bash
git commit -m "Added new files"
```

**4. Differences between HTML and CSS**

| HTML                                                 | CSS                                                       |
| ---------------------------------------------------- | --------------------------------------------------------- |
| HTML stands for HyperText Markup Language.           | CSS stands for Cascading Style Sheets.                    |
| HTML is used to create the structure of a webpage.   | CSS is used to style a webpage.                           |
| It defines headings, paragraphs, images, links, etc. | It defines colors, fonts, spacing, borders, layouts, etc. |
| HTML uses tags.                                      | CSS uses selectors and properties.                        |
| Example: `<h1>Hello</h1>`                            | Example: `h1 { color: blue; }`                            |

**5. Explain IF statement with an example in JavaScript**

The **if statement** is used to execute a block of code when a given condition is true.

**Syntax:**

```javascript
if (condition) {
    // statements
}
```

**Example:**

```javascript
let age = 20;

if (age >= 18) {
    console.log("You are eligible to vote");
}
```

**Output:**

```text
You are eligible to vote
```

Here, the condition `age >= 18` is true, so the statement inside the `if` block is executed.
